# HPC Local-to-Remote Hybrid Workflow

A secure framework to write code locally with Claude, bypass cluster Multi-Factor Authentication (MFA/Duo) using SSH connection multiplexing, and submit Slurm scripts directly to a university high-performance computing (HPC) environment.

---

## ⚙️ Configuration Setup

Before running the workflow, customize the following configuration fields in your project files:

### 1. In `deploy.sh`
Update lines 5 to 9 with your university login information:
```bash
# --- CONFIGURATION ---
REMOTE_USER="your_username"          # <-- Change to your cluster username
REMOTE_HOST="cluster.university.edu" # <-- Change to your cluster's login node address
REMOTE_DIR="~/hpc-test-project"      # <-- Target project folder path on the cluster
# ---------------------
```

### 2. In `jobs/submit.slurm`
Update line 8 with your university's specific Slurm resource allocation queue:
```bash
#SBATCH --partition=standard       # <-- Change "standard" to your school's queue (e.g., gpu, short, compute)
```

---

## 🚀 How to Run (Step-by-Step)

Execute all commands from your **local machine terminal** inside the root project directory.

### Step 1: Open the Secure MFA Tunnel
Run the deployment script to establish the background SSH tunnel. **You only have to complete your university MFA/Duo challenge once.**
```bash
./deploy.sh
```
*This command auto-creates the remote directory, syncs your local files up to the cluster, and automatically submits your Slurm job.*

### Step 2: Monitor Your Job Status
Check if your job is pending (`PD`), running (`R`), or complete by checking the cluster queue through your active tunnel:
```bash
ssh -S "./.ssh_control/ssh_mux_${REMOTE_HOST}_22_${REMOTE_USER}" "${REMOTE_USER}@${REMOTE_HOST}" "squeue -u ${REMOTE_USER}"
```
*(When this command returns a blank line, your job has finished executing).*

### Step 3: Pull Down Your Results
Once your job clears the queue, fetch your log files and computational outputs back to your laptop without triggering another Slurm submission:
```bash
./deploy.sh --pull
```

## 📁 Directory Structure
Expect the following file structure when test case files are successfully written out:
```text
hpc-test-project/
├── deploy.sh             # Main orchestration script (Handles MFA, rsync, and sbatch)
├── README.md             # This file
├── results.txt           # Generated by the cluster (Appears locally after running --pull)
├── jobs/
│   ├── submit.slurm      # Your cluster resource configuration script
│   ├── output_*.log      # Live print statements from the compute node
│   └── error_*.log       # System crash dumps / Python error logs
└── src/
    └── test_job.py       # Your active Python codebase / calculation scripts
```
